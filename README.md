# Reactix – Virtual Chemistry Lab 

An iOS-based virtual chemistry lab that allows students to safely perform chemistry experiments in a simulated environment.

## 🚀 Features
- Interactive 3D lab environment  
- Realistic experiment simulations  
- Microscopic view for detailed observation  
- Smooth performance with optimized rendering  

## 🛠 Tech Stack
- SwiftUI  
- SceneKit  
- 3D Models
